# Network Analyzer has moved

The maintained project is now [apakoning/network-analyzer](https://github.com/apakoning/network-analyzer).

```bash
git clone https://github.com/apakoning/network-analyzer.git
```

The standalone repository contains collection, analysis, plotting, installation instructions, example data and automated checks. Earlier versions remain in this repository’s Git history. Existing CSV logs remain compatible; failed measurements are handled more accurately by the new version.
