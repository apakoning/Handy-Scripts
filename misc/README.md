# Miscellaneous utilities

- `usb-status.sh`: reports USB topology, devices and available USB-C power-role information; requires `usbutils`.
- `find_pdf_with_progress.sh`: searches mounted non-system filesystems for a filename; pass the filename as the first argument. Large filesystems can take time to scan.

Historical installers, personal downloads and network prototypes are under [archive](../archive/README.md). The CLI installer is at [system/setup/install_modern_cli_tools.sh](../system/setup/install_modern_cli_tools.sh).
